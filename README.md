**Data Analytics Internship Projects - CodeAlpha**

This repository contains the completed tasks for the CodeAlpha Data Analytics Internship program. 


## Completed Tasks

  Task 1: Web Scraping (`scraper.py`) — Extracted structured quote data into `quotes_dataset.csv`.
  Task 2: Exploratory Data Analysis (`eda.py`) — Analyzed datasets and saved visual statistics (`top_authors.png`).
  Task 3: Data Visualization (`visualization.py`) — Built plots including `author_quotes_visualization.png`.
  Task 4: Sentiment Analysis (`sentiment.py`) — Evaluated text sentiment and generated `quotes_with_sentiment.csv`.

## Tech Stack
- Python
- Pandas, BeautifulSoup4, Requests, Matplotlib, Seaborn
